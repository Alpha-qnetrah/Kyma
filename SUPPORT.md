# Support

Use GitHub Discussions for language questions and design proposals. Use the issue templates for reproducible compiler, runtime, CLI, packaging, and editor defects. Include `kyna --version`, the operating system and architecture, the smallest `.kyna` reproduction, the full diagnostic, and whether output was interactive or redirected.

Security reports must follow [SECURITY.md](SECURITY.md) and must not be filed publicly. The project does not provide private deployment support or guarantees for unreleased builds.
