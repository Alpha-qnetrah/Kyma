# Governance

Kyna is maintained by Ahmed Mansour under the Up-to-code GitHub account. Maintainers accept changes through reviewable pull requests and may appoint additional maintainers based on sustained technical and community contribution.

Language changes require an update to the relevant specification, compatibility impact, diagnostics, and conformance tests. Architecture changes must preserve the dependency direction documented in [docs/architecture.md](docs/architecture.md). Security fixes may be developed privately and merged at coordinated disclosure.

The code of conduct applies to every project space. Maintainers may reject changes that weaken safety boundaries, reproducibility, licensing clarity, or release integrity.
