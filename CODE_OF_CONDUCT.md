# Contributor Covenant Code of Conduct

We want Kyna to be a welcoming, respectful, and technically rigorous project. Participants must avoid harassment, discrimination, personal attacks, doxxing, and unwanted sexual attention. Constructive disagreement about code and language design is encouraged; criticism must address ideas and behavior, not people.

Project maintainers may remove comments, close discussions, or restrict participation when conduct violates this policy. Report abusive behavior privately through the repository’s security/contact channels.
